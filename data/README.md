# Data

The datasets used for the paper's results. In every file, class 1 is listed first.

| Path | Contents | Used for |
|---|---|---|
| `hidden_rotation/cutoff25.npz` | 100 + 100 two-mode kets, shape (25, 25) | Figs. 3, 8 (adaptive model) |
| `chirality/cutoff20.npz` | 100 + 100 three-mode kets, shape (20, 20, 20) | Fig. 5 |
| `sensing/params.npz` | 100 + 100 (squeezing, rotation) pairs, float32 | Fig. 7 |
| `shadow_features/{n}shots_fold{k}.npz` | shadow estimates of the 5 ASWAP features, train/val/test = 40/10/40 points, n = 100 … 50,000 | Fig. 8 (shadow baseline) |
| `hidden_rotation/cutoff10.npz`, `chirality/cutoff10.npz` | smaller, independently drawn versions; noticeably truncated (state norms² down to 0.67 and 0.62) | tutorials and tests only |

Load them with `cv_relational_learning.datasets.load_dataset` / `load_shadow_features`.

## Provenance

- **States** were prepared with the strawberryfields Fock backend by
  `datasets.make_hidden_rotation_dataset` / `make_chirality_dataset` (no seed was set at the time).
- **Sensing interactions** (cutoff² × cutoff² matrices) were originally stored in full (488 MB). Each
  is `(R(φ) ⊗ R(φ)) (I ⊗ S(r, ϑ))` with r and φ drawn by `torch.rand` in float32, so `params.npz` stores
  the recovered (r, φ). `datasets.sensing_interaction` rebuilds all 200 original matrices bit-for-bit.
- **Shadow features** were generated by `examples/make_shadow_features.py --fast --overwrite-paper-data` (seeds 0, 1, 2
  for train/val/test; the pair parameters are in `shadow_features/states.npz`). Fresh hidden-rotation pairs are drawn
  and 250,000 random-quadrature homodyne shots of each single pair are sampled. Realisation k of budget n uses shots
  [k·n, (k+1)·n) of the same pair. `--fast` switches on two problem-specific speedups that are exact for this task
  (Gaussian-moment sampling and an O(cutoff²) feature formula); without it the script runs the generic pipeline
  (strawberryfields sampling per shot, features from reconstructed shadow states), which gives statistically equivalent
  features but takes many hours at this scale.
